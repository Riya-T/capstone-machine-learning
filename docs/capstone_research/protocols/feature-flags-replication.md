# Feature Flags comparison

This is a separate task-family comparison. No editing outcomes for
these parents were used in selection. From the six saved teacher
writer comparison families, select the alphabetically first family
with multiple passing programs that store the same core state in
substantively different representations. Calendar Events, Document
Store and Event Bus each had one core state representation in the
four saved starts. Feature Flags was next and eligible. Sample 00
stores one (rollout, user set) record per flag. Sample 01 maintains
separate maps for rollouts and user overrides. Samples 02 and 03
also use separate maps. Select the lowest-numbered member of each
group. Both are neutral teacher outputs.

Use both existing two-change sequences. Recheck the original initial
public and private suites, the previously certified teacher-writer
supplement, and an independent initial rollout and override oracle.
At every later checkpoint include that oracle and the previously
certified teacher supplement as preserved behavior. At the second
checkpoint of groups then kill switch, also score the existing
certified group/kill interaction separately. The auditor checks the
references and a deliberate negative control for each supplement
before inference.

Reuse the Stock Portfolio replication submission policy, model,
budgets and paired scheduling rule with separate recorded seeds
and a separate two-hour window. The maximum is 24 checkpoints.
No repairs, training, or new hosted calls. Do not expose future
requests, private checks, sibling source or outcomes.

This family has no earlier direction to confirm. Count both directions
with the same numerical threshold. A discovery direction requires
complete behavioral outcomes, a strict lead on each sequence, at
least three successful checkpoints of advantage, and a lead in
at least two of three blocks. The direction must survive every
possible outcome of budget-draft-dependent trajectories. Replay
every submitted artifact and investigate defects before reporting.
Any winner here is a discovery candidate that requires a separate
fresh confirmation. Assign no training labels.
