# Teacher-backed writer comparison

This final bounded fallback measures a change in the operational writer.
It uses the same initial contract, public examples and private evaluator
for the local and subscription workspace writers. There is no training
or adapter update. A positive result establishes improved initial
correctness for this writer replacement on these families. Later editing
success and the supply of local training pairs remain separate questions.

## Roster and inputs

Use Calendar Events, Document Store, Event Bus, Feature Flags, Adventuring
Party and Warehouse Stock. These six team training-split families were
outside the current pair study and writer-selection experiment. Some
have historical baseline observations or contract surveys. No code or
prompt was trained or tuned using these test outcomes. The team's
official evaluation split is untouched.

Lock four matched blocks per family, one local reasoning-writer request
and one subscription workspace-writer request per block. Stop at 24
requests per arm. Both receive only the same initial specification,
supplied public checks and one supplementary public example. The hosted
writer saves a workspace artifact; the local writer returns a complete
fenced file. This transport and the model both change. No result is
attributed to either component in isolation. Record malformed outputs,
errors and stops without retrying or generating substitutes.

Evaluate every saved candidate on unchanged public and private tests
and on an independently labeled state/lookup supplement. Validate the
supplement on the reference and a deliberately incorrect control
before generation. Any failed certificate stops that family. Neither
model sees private results, sibling sources, future requirements or
the other model's output.

## Settings and decision

Use the existing pinned Qwen3-8B Q8_0 and Linux runtime for the local arm.
Use gpt-6.1-sol, medium and the existing verified workspace worker for
the hosted arm. Keep the earlier 65%-used planning ceiling, two-point
projection margin, at least 30% actual weekly reserve, serial hosted
calls and fresh before/after observations. Any changed allowance
window, unexplained jump or unavailable reading closes hosted work.
Both arms run serially within themselves and use their own resource
limits. This comparison does not claim equal compute or equal cost.

A verified improvement requires all 24 pairs to have accounted-for
outcomes with no missing or infrastructure errors, more full passes in
at least four families, no family with fewer passes, and at least six
net full passes. Require the same numerical conditions on the independent
private outcomes alone. Malformed source counts as an unsuccessful
writer submission. Replay every full-correctness disagreement privately
using unchanged artifacts and reproduce all outcomes. Report results
over families and raw attempts. Keep all source provenance and usage.

If this gate passes, a teacher-backed writer has a verified initial
correctness advantage on the fixed comparison. This leaves the trained
checkpoint and maintainability claim unresolved. The capstone's original
weights and all evaluation files remain intact.
